# 원윤메디팜 주문 사이트

거래처(약국·병의원)가 아이디로 로그인해 의약품·의료소모품을 직접 주문하고, 원윤메디팜이 주문 확인 → 출고 → 정산 → 전자세금계산서 발행까지 처리하는 사이트입니다.

## 구성
- `index.html`, `app.js`, `assets/` — 화면 (GitHub Pages로 공개)
- 데이터·로그인 — Supabase 프로젝트 `wonyun-medipharm` (서울 리전)
- `supabase/functions/admin-users` — 거래처·관리자 아이디 발급, 비밀번호 재설정, 잠금
- `supabase/functions/tax-invoice` — 볼타 API로 전자세금계산서 발행·상태 확인·PDF
- `supabase/functions/drug-info` — 식약처 의약품 정보 조회 (공공데이터포털)

## 재고 요청
- 거래처 주문 화면에서 품목마다 '주문 가능 / 주문 불가'가 보여요. 재고 관리 품목은 재고 0, 그 외는 관리자가 '일시 품절'로 표시하면 주문 불가예요 (서버에서도 막음).
- 주문 불가 품목은 '재고 요청', 목록에 없는 약품은 '약품 보유 요청'을 남길 수 있어요.
- 관리자 '재고 요청' 메뉴에서 확인 중·입고 완료·보유 불가로 처리하고 안내 문구를 남겨요. 입고를 등록하거나 일시 품절을 풀면 그 품목 요청은 자동으로 입고 완료돼요.

## 식약처 의약품 정보
- 거래처가 주문 화면에서 약품명을 검색하면 식약처 공공데이터(제품 허가정보·e약은요·낱알식별)로 성분·효능·용법·주의사항·사진을 보여 줘요.
- 우리 상품과 보험코드(또는 이름)가 맞으면 바로 담기, 품절이면 재고 요청, 취급하지 않으면 보유 요청(식약처 코드 함께 저장).
- `supabase/functions/drug-info` — 공공데이터포털 호출·캐시(drug_cache, 검색 7일·상세 30일). 비밀값 `DATA_GO_KR_KEY`(공공데이터포털 일반 인증키)가 있어야 켜져요. 키가 없으면 거래처 화면에는 아무것도 안 보여요.

## 글꼴
- 제목·워드마크·큰 숫자: 페이퍼로지(Paperlogy, PT&, SIL OFL 1.1) — `assets/fonts`에 웹용(woff2)으로 변환해 둠. 글꼴 안에 저작권·라이선스 표기 유지.
- 본문: 프리텐다드(Pretendard, SIL OFL 1.1) — jsDelivr에서 불러옴.

## 보안
- 이 저장소에는 공개용 키(publishable key)만 들어 있습니다. 데이터 접근은 Supabase 권한 규칙(RLS)으로 막혀 있어, 거래처는 자기 거래처의 주문·단가·세금계산서만 볼 수 있습니다.
- 주문 단가는 서버에서 다시 계산하므로 화면에서 바꿀 수 없습니다.
- 볼타 API 키는 Supabase Edge Function 비밀값 `BOLTA_API_KEY`에만 저장합니다. 이 저장소에 넣지 마세요.

## 세금계산서 연동 순서
1. bolta.io 가입 → 개발자센터에서 테스트 키(`test_…`) 발급
2. Supabase 대시보드 → Edge Functions → Secrets에 `BOLTA_API_KEY` 등록
3. 사이트 관리자 → 설정 → 회사 정보 저장 → 발급자 등록 → 공동인증서 등록
4. 테스트로 발행해 보고, 준비되면 라이브 키(`live_…`)로 바꾸기
